بیمه‌یار — نسخهٔ به‌روزشدهٔ رابط سایت

محتویات بسته:
- index.html: سایت فارسی راست‌چین با رنگ‌های بنفش، آبی و زرد.
- supabase-schema.sql: طرح اولیهٔ پایگاه دادهٔ Supabase موجود در بستهٔ پایه.
- README.txt: توضیحات و محدودیت‌ها.

تغییرات این نسخه:
1) نام محصول و عنوان‌های رابط به «بیمه‌یار» تغییر کرده است.
2) دکمهٔ استعلام هر بیمه ابتدا پنجرهٔ انتخاب مقصد را باز می‌کند: ازکی، بیمه‌دات‌کام یا بیمه‌بازار.
3) بخش «مقایسهٔ یک بیمه در سه سایت» اضافه شده است. کاربر یک نوع بیمه را انتخاب می‌کند و برای همان نوع، لینک هر سه ارائه‌دهنده را می‌بیند.
4) پالت رنگ رابط به بنفش، آبی و زرد تغییر کرده است.

نکتهٔ مهم دربارهٔ مقایسه:
این نسخه قیمت یا پوشش‌ها را به‌صورت خودکار از سه شرکت دریافت نمی‌کند. فقط مسیر استعلام همان نوع بیمه را در هر سه سایت باز می‌کند. نمایش مقایسهٔ واقعی قیمت، فرانشیز، سقف تعهدات و پوشش‌ها نیازمند API رسمی، قرارداد همکاری یا دادهٔ قابل اتکای مجاز از هر ارائه‌دهنده است. هیچ قیمت ساختگی نمایش داده نمی‌شود.

لینک‌های مقصد فعلاً به دامنهٔ اصلی هر ارائه‌دهنده می‌روند، نه صفحهٔ اختصاصی هر نوع بیمه؛ چون مسیرهای عمیق/اختصاصی باید جداگانه تأیید شوند:
- https://www.azki.com/
- https://bimeh.com/
- https://bimehbazar.com/

راه‌اندازی روی Netlify:
1) ZIP را استخراج کنید.
2) فایل index.html را در ریشهٔ پوشهٔ انتشار قرار دهید.
3) پوشه را در Netlify منتشر کنید یا آن را به مخزن Git متصل کنید.
4) پس از انتشار، روی موبایل و دسکتاپ دکمه‌های انتخاب مقصد و بخش مقایسه را آزمایش کنید.

پایگاه داده و امنیت:
فایل SQL موجود در این بسته، ساختار اولیهٔ Supabase است؛ اما این به‌روزرسانی رابط، اتصال جدید Supabase را در JavaScript فعال نمی‌کند. اگر نسخهٔ قبلی شما از قبل به Supabase متصل شده، قبل از جایگزینی index.html، کد اتصال و احراز هویت همان نسخه باید با این رابط ادغام شود. کلید service_role یا رمزهای مدیریتی را هرگز در HTML قرار ندهید.

توجه:
این ZIP یک بستهٔ وب برای انتشار روی Netlify است، نه APK اندروید. پیش از انتشار عمومی، مقصدها و سیاست حریم خصوصی را بررسی کنید.
